# 1.2.7 Extended Audio Description (Prerecorded)

## Learning objectives

Recognize when ordinary pauses cannot accommodate necessary audio description, and explain how extended audio description supplies the missing time. This criterion is Level AAA.

## Why extra time can be needed

Audio description communicates important visual information during a recording. Some sequences contain continuous foreground speech while important actions unfold. A description squeezed into a tiny gap may be too brief to convey the action, while narration placed over the original speech may make both difficult to understand.

Extended audio description pauses the presentation to allow additional description, then resumes it. The criterion applies where pauses in foreground audio are insufficient for audio descriptions to convey the sense of prerecorded video in synchronized media. The need depends on whether meaningful visuals can be conveyed in the available pauses, not merely on whether the recording contains speech.

## Plan an extended version

Review a recording alongside its existing narration. Identify significant visual information that is absent from the soundtrack. Draft clear descriptions and test whether they fit in available pauses without obscuring important audio. Where the necessary description will not fit, select a pause point, stop the presentation, provide the extended description, and resume at the correct point. Make the extended version or feature discoverable and test its controls.

For example, a presenter continuously explains a process while a silent diagram changes through three important states. An extended version can pause before the next step to describe those changes. A single phrase such as “diagram changes” may omit the relationship between the states, so check that the listener can follow the process.

## Related criteria

Standard audio description is addressed by 1.2.5 at Level AA; extended description addresses the additional situation where ordinary pauses are insufficient. Captions expose audio in text and do not substitute for visual description. Evaluate the media as a whole and make sure any description preserves the original information rather than inventing details.

## Worked example: a chart animation

A speaker continuously explains sales figures while an animated chart changes from monthly to quarterly totals. The color of each series and the axis labels also change, but none of this is spoken. The only natural pause is a fraction of a second, too short to describe the relevant transformation. An extended version can stop the presentation at the change, describe the axes and the relevant relationship between the series, and then resume before the next explanation.

A poor fix places a long description over the speaker's explanation. The listener would have to understand two competing pieces of audio. Another poor fix simply says “chart changes,” leaving the important comparison unclear. Describe what the viewer needs in order to understand the sequence and avoid inferring values the chart does not show.

## Review the timing

Mark each visual event and the audio that occurs at the same time. Draft a concise description, read it aloud, and compare its duration with the available pause. When it will not fit, choose a point that maintains the meaning of the sequence, pause the media, and resume without skipping the original content. Test seeking and playback of the extended version, and ask a listener to explain the chart using only the audio. Revise timing or description when the listener misses a meaningful relationship.

## Compare a normal pause with an extended pause

Suppose a narrator says “First, open the profile,” pauses for four seconds, and then describes the next step. The screen silently shows the profile button being selected. If a concise description of the important action fits naturally in the four-second pause, extended description may not be needed for that moment. Test the actual audio and visuals instead of counting pauses without considering the information that must fit.

In a second sequence, the narration continues while three warnings appear in succession and affect the following decision. A single short pause cannot convey their content and order. An extended version can pause at the appropriate point, describe the warnings, and then resume the original media. It should retain the original spoken instructions; replacing them with description would sacrifice one set of information to provide another.

Mark description points in a script and compare the finished version with the original. Are events described before a listener needs to understand their consequences? Does playback resume at the correct location? Can users reach the extended version? If users can select between standard and extended versions, label them clearly and test the controls. These checks help expose sequencing and delivery errors that may not be obvious from reading a description script alone.

## Required lesson activity

Examine a clip with continuous speech and a meaningful visual change. Write the missing description, identify the available pauses, and decide whether it fits without covering important audio. If it does not fit, propose a pause and resume point and explain why the extended version is needed.

## Mini-assessment

1. When does 1.2.7 require extended audio description?
2. What happens to the video while an extended description is delivered?
3. Why is a vague description of a changing diagram potentially inadequate?

Suggested answers: When foreground-audio pauses are insufficient to convey the sense of the video; the presentation pauses and resumes after description; it may omit meaningful changes and relationships.
